# Desktop League of Legends Champion (with Editor)

Display a **League of Legends** model on the screen.

- With character **animations**
- With character **voices**
- With an **Editor**, you can extract the character model and voices of **League of Legends**, and then build your own model data. Please refer to the [wiki](https://github.com/ssnangua/desktop-lol-champion/wiki) for details.

<img src="./preview.gif" width="300px">

## Development

Get the sample character **model** and **voices** from [**Releases**](https://github.com/ssnangua/desktop-lol-champion/releases).

Or extract the character **model** and **voices** from **League of Legends** and generate the `.glb` file yourself. Please refer to the [**wiki**](https://github.com/ssnangua/desktop-lol-champion/wiki) for details.

```bash
# install
cd src
npm install
cd ..
npm install

# dev
npm run dev

# build
npm run build
```
